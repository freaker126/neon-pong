# 🏓 Freaker126 Neon Pong

A retro-arcade, neon-themed Pong game built with HTML5 Canvas, CSS, and Vanilla JavaScript. Playable directly in any web browser with smooth control physics and vibrant glowing visuals.

## 🕹️ Live Demo
Play the game live on GitHub Pages:
👉 **[Play Freaker126 Neon Pong Here](https://freaker125.github.io/neon-pong/)**

---

## ✨ Features
* **Retro Visuals:** Custom glowing neon aesthetics built with CSS and Canvas rendering.
* **Responsive Gameplay:** Smooth paddle physics and real-time collision detection.
* **Zero Dependencies:** Pure HTML5, CSS3, and JavaScript—no heavy external frameworks or libraries.
* **Instant Browser Play:** Works right out of the box on modern web browsers.

---

## 🛠️ Built With
* **HTML5:** Game structure and `<canvas>` rendering context.
* **CSS3:** Retro styling, neon glow filters, and layout.
* **JavaScript (ES6):** Game loop, collision physics, and input listeners.

## 🚀 How to Run Locally

1. **Clone or Download the repository:**
   Download `index.html` from this repository directly to your computer.
2. **Open the project:**
   Double-click `index.html` to open and play directly in your browser—no local server setup required!

---

## 🧠 Key Mechanics & Learning Points
This project is designed to be beginner-friendly for learning browser game development. Key sections inside `index.html` cover:
* **The Game Loop:** Utilizing `requestAnimationFrame` for smooth frame updates.
* **Collision Detection:** Bounding-box ball bounce physics against walls and paddles.
* **Input Handling:** Capturing keypress events for responsive player movement.
